# Muhammad Muneeb — Professional CV Website

A responsive personal CV website built with **HTML, CSS and JavaScript**, ready to open in Visual Studio Code and publish with GitHub Pages.

## Project structure

```text
muneeb_cv_website/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── profile.jpg
```

## Run locally

1. Extract the ZIP file.
2. Open the `muneeb_cv_website` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

No build tools or package installation are required.

## Before publishing

In `index.html`, find the **GET IN TOUCH** section and replace:
- `[Add your phone number]`
- `[Add your email address]`
- `[Add your city]`

Review the details and make sure they are current.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `muhammad-muneeb-cv`.
2. Upload the contents of this folder (the files and `assets` folder — not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish your website. The public URL will appear in the Pages section.

## Features

- Responsive layout for desktop, tablet and mobile.
- Your supplied profile photo.
- Sections for profile, work experience, industry exposure, education, training, skills and languages.
- Mobile navigation menu.
- Print / Save as PDF button with print-friendly styling.

## Note

This is a web CV, so the interactive browser behavior is written in **JavaScript** (not Java). The page itself is HTML and its visual design is CSS.
